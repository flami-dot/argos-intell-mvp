# ARGOS INTELL MVP

Responsive static web prototype for the ARGOS INTELL geospatial intelligence platform.

## Publish with GitHub Pages
1. Open repository Settings → Pages.
2. Under Build and deployment, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. Wait for the deployment and open the Pages URL shown there.

## Prototype features
- Responsive dashboard and mobile navigation
- Six sector modules: agriculture, mining, infrastructure, logistics, environment, water
- Synthetic map-like visualizations and charts
- Project creation and filtering in current page session
- Simulated alerts
- Downloadable HTML sample reports
- Investor showcase and EOSDA integration status checklist

## Important
All map zones, metrics, charts, and alerts are synthetic. This is a frontend prototype only: no real satellite imagery, EOSDA API integration, backend, authentication, or persistent database. Project changes are lost on reload. Keep any future EOSDA API key on the server, never in frontend code.
